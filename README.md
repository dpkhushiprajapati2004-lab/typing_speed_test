# Typing Speed Test (Python)

## Overview
A command-line application that tests typing speed and accuracy. It shows a random sentence, times how long the user takes to type it, and then displays the results.

## Features
- Picks a random sentence from a list for each test
- Measures time taken using the time module
- Calculates typing speed in words per minute (WPM)
- Calculates accuracy by comparing the typed text with the original, character by character

## Tools Used
Python, VS Code, github copilot

## How to Run
1. Install Python 3
2. Download typing_test.py
3. Run: python typing_test.py
4. Type the sentence shown and press Enter

## Sample Output
Time taken: 12.4 seconds
Typing speed: 54.19 words per minute
Accuracy: 97.73%
